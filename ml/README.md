# LPGSafe Bangladesh — Machine Learning Module

This directory is prepared for **Part 4** of the LPGSafe Bangladesh platform:
- Safety Risk Prediction (Logistic Regression, Random Forest, XGBoost)
- Price Anomaly Detection (Isolation Forest)
- Demand Forecasting (XGBoost / Time Series)
- Complaint Classification (NLP / TF-IDF + Classifier)

The AI models will serve as decision-support tools for inspectors, regulators, and platform admins.
